# Puzzle Play

Drag-and-drop jigsaw puzzles for children aged 3 to 10. Pick how many pieces,
pick a picture, drag the pieces into the frame, and the picture appears.

No build step, no dependencies, no image files, no accounts, no ads, no timer
and no way to lose. The whole thing is about 55 KB of hand-written code and
works offline once loaded.

**Live: https://kiran-maturi.github.io/kidpuzzles/**

## How it plays

| | |
|---|---|
| **4 pieces** | ages 3–4 |
| **9 pieces** | ages 5–6 |
| **16 pieces** | ages 7–8 |
| **25 pieces** | ages 9–10 |

Twelve pictures — rocket, cat, fish, house, truck, butterfly, rainbow, apple
tree, sailboat, dinosaur, train, flower. Finishing one earns a star, kept in
`localStorage`, shown on its card on the home screen.

Choices that come from the age range rather than from convenience:

- A piece dropped in the wrong place **stays where it was dropped**. Springing
  it back to the tray reads as punishment to a small child.
- The snap radius is a third of a piece, so close enough is enough.
- Placed pieces stop responding to touch, so a finished corner cannot be
  knocked apart by a stray palm.
- Under 7s get the picture faintly behind the frame as a guide (🖼 toggles it).
- Nothing is timed or scored, and the celebration lands in the empty tray so
  the finished picture — the actual reward — stays in full view.
- Every control carries an emoji as well as a word, because much of the
  audience cannot read yet.

Keyboard play works too: <kbd>Tab</kbd> to a piece, arrow keys to move it
(<kbd>Shift</kbd> for bigger steps), <kbd>Enter</kbd> to seat it.

## How it works

There are no image files. Each picture is hand-written SVG in
[`js/scenes.js`](js/scenes.js), drawn in a 400×400 space with flat bold shapes.

The cut ([`js/pieces.js`](js/pieces.js)) is the interesting part. Every interior
edge gets one knob, and the two pieces sharing that edge draw the *same* curve —
one as a tab, one as a blank — so a piece fits in exactly one place. Each piece
is then its own `<svg>` whose `viewBox` is that piece's window onto the scene,
with the full scene markup dropped in and clipped to the piece outline. The
artwork is never sliced, so pieces stay vector-crisp at any board size, and the
cut is seeded per picture-and-size so a resize never reshuffles the shapes.

Pieces hit-test on their painted shape rather than their bounding box, so
overlapping pieces in the tray pick up the one actually under the finger.

The app icon is generated by the same cutting code — see
[`icons/icon.svg`](icons/icon.svg).

## E Ink mode

Built to also run on a 6–7" Boox-style E Ink tablet, where colour does not
exist, animation smears and ghosting lingers. The 🖤 button (auto-enabled when
the user agent looks like an E Ink device) switches to high-contrast grayscale,
disables every transition and animation, thickens the piece outlines, moves
drags in 10px steps instead of continuously so the screen repaints a handful of
times per drag, and adds a ⟳ button that flashes the screen to clear ghosting.

## Running it

Any static server — ES modules will not load over `file://`:

```bash
python3 -m http.server 8765   # then open http://localhost:8765
```

The service worker is deliberately skipped on localhost; a cache-first worker
during development just serves yesterday's JavaScript.

## Deploying

The repo root is the site. `.github/workflows/pages.yml` publishes it on every
push to `main`. Pages has to be told once to take its content from Actions:
**Settings → Pages → Source: GitHub Actions**. After that:

```bash
git add -A && git commit -m "..." && git push
```

When any file changes, bump `CACHE` in [`sw.js`](sw.js) — otherwise tablets keep
serving the previous build from disk.

## Layout

```
index.html                 markup for both screens
styles.css                 all styling, including the E Ink block
js/scenes.js               the twelve pictures, as SVG
js/pieces.js               jigsaw cutting: knobs, clip paths, piece markup
js/game.js                 board/tray layout, snapping, progress
js/drag.js                 pointer dragging
js/audio.js                synthesised sounds — no audio files
js/eink.js                 E Ink detection, preference and screen flash
sw.js                      offline cache
```
